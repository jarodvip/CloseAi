# 数据模型设计

## 1. 用户表 users
- id：主键
- username：用户名（唯一）
- hashed_password：哈希密码
- role：角色（admin / user）
- is_active：是否激活

## 2. 客户表 customers
- id：主键
- owner_id：归属用户（外键 users.id）
- name：客户名称
- industry：行业
- revenue_range：营收区间
- stage：发展阶段
- region：区域
- primary_type：主客户类型
- secondary_type：次客户类型
- type_confidence：类型置信度
- type_evidence：类型判断依据
- created_at / updated_at

## 3. 跟进记录表 interactions
- id：主键
- customer_id：客户ID（外键）
- stage：会前/会中/会后
- transcript：对话记录
- summary：会话摘要
- decisions：决策结果
- pending_actions：待办动作
- created_at

## 4. 简报历史表 briefing_history
- id：主键
- customer_id：客户ID
- session_id：关联会话ID
- customer_name：客户名称
- primary_type / secondary_type：客户类型
- confidence：置信度
- evidence：判断依据
- opening_line：切入话术
- focus：关注重点
- next_step：下一步动作
- recommended_cases：推荐案例
- potential_objections：潜在异议
- source_refs：来源引用
- llm_text：LLM 增强文本
- llm_source_cards：LLM 来源卡片
- created_at

## 5. 会话/消息表 chat_sessions + chat_messages
- chat_sessions：id, customer_id（可选）, title, created_at
- chat_messages：id, session_id（级联删除）, role, content, meta（JSON）, created_at

## 6. 外部数据层 research_chunks
- id：主键
- source_type：来源类型（doc / web / research）
- title：标题
- url：来源 URL
- source_name：来源名称
- industry：行业标签
- customer_id：关联客户（背调结果）
- content：文本内容
- chunk_index：分块序号
- fetched_at：抓取时间
- created_at：入库时间
- embedding：预留向量（二期使用）

## 7. 知识库基础表
- customer_type_knowledge：客户类型结构化知识（code, name, signal, pain, strategy, opening_line, taboo, objections, next_step 等）
- cases：案例库（code, title, type, industry, stage, result, source）
- scripts：话术库（scene, type, template, source）
- evidence：数据证言库（source, metric, value, scene, source_ref）

## 8. 索引建议
- customers：name、primary_type、industry、owner_id
- interactions：customer_id、created_at
- briefing_history：customer_id、created_at
- chat_messages：session_id、created_at
- research_chunks：customer_id、source_type、industry

## 9. v0.8 知识飞轮新增表
- feedback：来源卡反馈（username, scene[briefing/assist/followup/chat], customer_id, source, label, rating[up/down], comment, created_at）。驱动采纳率看板。
- llm_call_logs：LLM 调用观测（scene, model, success, degraded, degrade_reason[no_api_key/request_error], prompt_tokens, completion_tokens, latency_ms, error, created_at）。写入失败不影响业务。
- knowledge_suggestions：知识沉淀建议草稿（customer_id, customer_name, username, suggestion_type[script/case/evidence], scene, ktype, title, industry, content, status[pending/approved/rejected], note, reviewed_by, reviewed_at, created_at）。会后跟进自动生成，admin 审核通过后写入 scripts/cases/evidence 对应表。

## 10. 索引补充（v0.8）
- feedback：username、scene、customer_id
- llm_call_logs：scene、created_at
- knowledge_suggestions：customer_id、status
- research_chunks.embedding：LargeBinary 向量列（f32 little-endian blob），供混合检索使用

## 11. v1.0 团队与集成变更
- users：已有 is_active（禁用即失效）；初始 admin 由 ADMIN_INITIAL_PASSWORD 引导，不再硬编码种子账号
- cases / scripts：新增 owner_username（NULL=全局种子数据）、is_shared（共享后进入团队检索池）。可见性：admin 全量；普通用户可见 共享 + 本人 + 全局；简报/会中/会后检索池仅取 共享+全局
- crm_push_logs：CRM webhook 推送留痕（username, customer_id, customer_name, success, http_status, error, payload_summary, created_at）
