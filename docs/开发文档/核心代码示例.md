# 核心代码示例

## 1. 启动后端
```bash
cd /Users/jarod/Dev/sales/backend
source .venv/bin/activate
uvicorn app.main:app --reload --host 127.0.0.1 --port 8002
```

## 2. 启动前端
```bash
cd /Users/jarod/Dev/sales/frontend/src
python3 -m http.server 8080
```

## 3. 登录示例
```bash
curl -X POST http://127.0.0.1:8002/api/v1/auth/login \
  -H 'content-type: application/json' \
  -d '{"username":"admin","password":"admin123"}'
```

## 4. 会前简报示例
```bash
curl -X POST http://127.0.0.1:8002/api/v1/customers/1/briefing \
  -H 'Authorization: Bearer <token>'
```

## 5. 知识库后台示例
```bash
curl http://127.0.0.1:8002/api/v1/knowledge/cases \
  -H 'Authorization: Bearer <token>'
```

## 6. 固定测试脚本
- 完整重启并跑 pytest：`bash scripts/run_tests_with_restart.sh`
- 前端冒烟测试：`python3 scripts/frontend_smoke_test.py`
