# 技术架构

## 1. 总体架构
- 前端：静态 Web 演示页，直接调用后端 API
- 后端：FastAPI + SQLAlchemy + SQLite
- 数据层：关系型模型 + 可落盘的知识库基础表
- AI 层：规则生成 + LLM 增强，无 LLM 时自动降级

## 2. 后端模块
- `app/main.py`：应用入口、路由注册、初始化种子数据
- `app/core/security.py`：JWT 与密码哈希
- `app/core/deps.py`：登录态与权限依赖
- `app/routes/auth.py`：登录与当前用户
- `app/routes/customers.py`：客户 CRUD 与类型更新
- `app/routes/briefing.py`：会前简报生成
- `app/routes/interactions.py`：会中辅助与会后跟进
- `app/routes/knowledge.py`：知识库查询与管理
- `app/services/`：业务服务、LLM 调用与内容生成
- `app/models/`：SQLAlchemy 数据模型
- `app/schemas/`：请求/响应模型

## 3. 权限与安全
- 使用 JWT Bearer 鉴权
- 登录后可访问客户与会话能力
- 知识库写入接口仅允许 `admin` 角色
- 演示环境提供默认账号 `admin/admin123` 与 `sales/sales123`

## 4. 前端模块
- `frontend/src/index.html`：登录页、销售工作台、知识库后台、弹窗
- `frontend/src/app.js`：API 调用、状态管理、页面切换

## 5. 部署建议
- 后端运行：`uvicorn app.main:app --reload`
- 前端运行：`python3 -m http.server 8080`
- 数据文件：`/Users/jarod/Dev/sales/backend/sales_agent.db`
