# 项目初始化与运行

## 1. 环境要求
- Python 3.11+
- Node.js 18+，仅用于前端静态预览
- macOS / Linux / WSL
- 建议 IDE：Cursor / VS Code / Claude Code

## 2. 后端初始化
- 目录：`/Users/jarod/Dev/CloseAI/backend`
- 核心依赖：`fastapi uvicorn sqlalchemy pydantic pydantic-settings httpx bcrypt python-jose[cryptography] pypdf python-docx readability-lxml jieba`
- 开发依赖：`pytest pytest-asyncio`
- 启动命令：`cd backend && source .venv/bin/activate && uvicorn app.main:app --reload --port 8002`
- 环境变量（`.env`）：`SECRET_KEY`、`LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`、`DATABASE_URL`

## 3. 前端初始化
- 目录：`/Users/jarod/Dev/CloseAI/frontend/src`
- 技术栈：静态 HTML + JavaScript，直接调用后端 API
- 启动命令：`cd frontend && python3 -m http.server 8080`

## 4. 数据库初始化
- 使用 SQLite，默认文件：`backend/sales_agent.db`
- 启动时会自动建表并写入默认账号：`admin/admin123`（admin）、`sales/sales123`（user）
- 手动初始化命令：`cd backend && source .venv/bin/activate && python app/db/init_db.py`
- FTS5 全文检索：启动时自动创建，不支持时静默降级为 ILIKE

## 5. 知识库初始化
- 初始化命令：`cd /Users/jarod/Dev/CloseAI && source backend/.venv/bin/activate && python scripts/seed_knowledge.py`
- 导入来源：JSON 种子数据（客户类型、案例、话术、证据）

## 6. 外部数据导入
- PDF/Word 批量导入：`cd backend && source .venv/bin/activate && python scripts/import_docs.py <目录或文件> --industry <行业> --source-name <名称>`

## 7. 运行检查
- 后端健康检查：`GET /health`
- 前端访问：`http://localhost:8080`
- 固定端口：backend `8002`、frontend `8080`
- API 文档：`http://localhost:8002/docs`

## 8. 常用脚本
- `scripts/run_tests_with_restart.sh`：每次测试自动杀旧进程、初始化数据库、重启前后端、校验登录、跑 pytest
- `scripts/frontend_smoke_test.py`：前端页面级冒烟测试，覆盖登录、会话、会前/会中/会后、来源卡、知识库权限
- `scripts/seed_knowledge.py`：初始化知识库
- `backend/scripts/import_docs.py`：导入 PDF/Word 到外部数据层
- `backend/scripts/demo.py`：演示脚本
