# 项目初始化与运行

## 1. 环境要求
- Python 3.11+
- Node.js 18+，仅用于前端静态预览
- macOS / Linux / WSL
- 建议 IDE：Cursor / VS Code

## 2. 后端初始化
- 目录：`/Users/jarod/Dev/sales/backend`
- 核心依赖：`fastapi uvicorn sqlalchemy pydantic python-dotenv httpx bcrypt python-jose[cryptography]`
- 开发依赖：`pytest pytest-asyncio ruff mypy`
- 启动命令：`source .venv/bin/activate && uvicorn app.main:app --reload`
- 环境变量：`DATABASE_URL`、`LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`、`APP_ENV`

## 3. 前端初始化
- 目录：`/Users/jarod/Dev/sales/frontend/src`
- 技术栈：静态 HTML + JavaScript，直接调用后端 API
- 核心页面：登录、销售工作台、知识库后台、会前/会中/会后弹窗
- 启动命令：`python3 -m http.server 8080`

## 4. 数据库初始化
- 使用 SQLite，默认文件：`/Users/jarod/Dev/sales/backend/sales_agent.db`
- 启动时会自动建表并写入默认账号：`admin/admin123`、`sales/sales123`
- 手动初始化命令：`source backend/.venv/bin/activate && python app/db/init_db.py`

## 5. 知识库初始化
- 初始化命令：`source backend/.venv/bin/activate && python /Users/jarod/Dev/sales/scripts/seed_knowledge.py`
- 导入来源：两份销售 PPT 的结构化内容

## 6. 运行检查
- 后端健康检查：`GET /health`
- 前端访问：`http://localhost:8080`
- 当前固定端口：backend `8002`、frontend `8080`，前端 `baseApi` 已指向 `http://127.0.0.1:8002`
- API 文档：`http://localhost:8002/docs`

## 7. 常用脚本
- `scripts/run_tests_with_restart.sh`：每次测试自动杀旧进程、初始化数据库、重启前后端、校验登录、跑 pytest
- `scripts/frontend_smoke_test.py`：前端页面级冒烟测试，覆盖登录、会话、会前/会中/会后、来源卡、知识库权限
- `scripts/seed_knowledge.py`：初始化知识库
- `scripts/eval_type_classifier.py`：评估类型判断准确率
- `scripts/export_customer_report.py`：导出客户报告
