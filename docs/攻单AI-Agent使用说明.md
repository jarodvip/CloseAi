# 攻单 AI Agent 使用说明

> 版本范围：客户画像自动生成、AI 攻单策略、七大客户类型速查、异议处理、经典案例匹配、免登录本地记录与 PDF 拜访报告导出。

## 1. 产品定位

攻单 AI 是面向分众传媒销售团队的销售作战工作台。它不替销售人员做最终决策，而是把客户访谈中零散的行业、规模、老板关键词、竞争状态和拜访目标，整理成可执行的客户画像、攻单策略、话术、案例佐证和下一步行动。

系统的核心方法论来自分众七大客户类型与“听、认、比、算、定”攻单五步法。AI 输出必须以项目内置知识库为上下文；当信息不足时，应补充客户线索，而不是凭空补写客户事实。

## 2. 访问与数据特点

当前版本**免登录即可使用**。打开网站后直接进入“客户诊断”工作台，不需要注册或登录。网站入口为 [攻单 AI 工作台](https://gongdanai-h7miejwc.manus.space)。

攻单记录保存在当前浏览器的 `localStorage` 中，存储键为 `gongdan-ai-local-records`。因此，同一浏览器刷新页面后可以继续复习；换浏览器、换设备、清除站点数据或使用无痕窗口时，记录不会自动同步。不要在记录中填写不必要的个人隐私、商业机密或未获授权的敏感信息。

## 3. 推荐使用流程

建议销售人员在拜访前 10—15 分钟完成一次客户诊断。先进入“客户诊断”，按问诊顺序补充客户画像；随后查看主次类型与判断依据，检查 AI 给出的破冰话术、攻单五步和案例；最后导出 PDF 或保存到“我的记录”，作为拜访前复习材料。

| 阶段 | 销售动作 | 推荐产出 |
|---|---|---|
| 听 | 只问不推，收集行业、规模、老板原话、竞争状态、目标和背景 | 客户原始情报 |
| 认 | 用客户能听懂的一句话点破处境 | 客户确认“你理解我” |
| 比 | 调用同类型经典案例，不先堆媒体资源 | 案例佐证 |
| 算 | 将投入、试点范围、周期和预期指标说清楚 | 可评估的价值模型 |
| 定 | 锁定关键人、试点范围和下一次动作 | 明确推进计划 |

## 4. 客户诊断工作台

### 4.1 六步问诊

诊断页面采用逐步问答形式，每次只聚焦一个问题。页面顶部的进度条展示当前步骤，右上角“已采集情报”可以展开已填写字段，便于销售随时检查上下文。

| 问诊维度 | 需要回答的内容 | 典型预设选项 | 默认选择模式 |
|---|---|---|---|
| 品牌名称 | 客户当前经营的品牌名称 | 例如：花西子、飞鹤、波司登；建议填写正式品牌名 | 单选/自由输入 |
| 行业 | 客户属于哪个行业 | 食品饮料、美妆个护、母婴营养、服饰鞋服、家居家电、汽车出行等 | 单选 |
| 规模 | 客户处于什么体量或发展阶段 | 初创 0—1 亿、成长 1—10 亿、区域龙头、全国布局、上市公司等 | 单选 |
| 老板关键词 | 老板最近反复强调什么 | 做行业第一、我要出省、要做新品类、要讲资本故事、要打爆一个市场等 | 多选 |
| 竞争状态 | 客户正在面对什么外部压力 | 红海同质化、区域强出省弱、竞品已先投、线上流量变贵、线下认知不足等 | 多选 |
| 本次目标 | 这次拜访希望推动什么 | 建立品牌资产、抢占品类心智、核心城市打样、拓展全国市场、品牌年轻化等 | 多选 |
| 补充背景 | 记录原话、投放经历、决策链或当前卡点 | 预算敏感、老板未到场、线上效果不好、需要内部汇报、希望小范围测试等 | 多选或自由输入 |

每个维度都可以在“单选”和“多选”之间切换。单选适合快速锁定主线，多选适合表达复合型客户画像。点击预设标签后，标签会同步写入输入框；也可以直接手动编辑。多选内容使用“、”分隔。

### 4.2 问诊操作

“保存并进入下一问”会保留当前线索并进入下一步；“上一步”可以返回修正前面的问题；顶部已经完成的进度段可以点击回看。最后一步按钮变为“生成攻单结论”，点击后由 AI 进行结构化诊断。

第一步新增“客户品牌名称”字段。填写品牌正式名称后，AI 会在诊断提示词中把品牌与行业、规模、老板原话、竞争状态一起分析；客户画像标题、保存记录标题、复习 Markdown 和 PDF 报告也会带上该品牌名称。若品牌名称暂时未知，可以填写“待确认品牌”，后续再回到该步骤修正。

建议优先填写客户原话，而不是销售人员的二次判断。例如，“老板说今年一定要出省”比“客户有全国化意愿”更利于模型判断。若某一项暂时未知，可以填写“待确认”，并在拜访中继续补齐。

## 5. 四模块销售闭环

完成客户诊断后，结果页会直接提供“进入攻单助手”和“查看类型卡”两个入口。前者把当前品牌、行业、主次类型、诊断结论和攻单策略带入助手，后者高亮当前识别到的七大类型，便于销售复核识别信号、切入点和沟通忌讳。

进入“异议速查”后，如果已经完成诊断，页面会展示当前品牌与客户类型，并提供“生成针对当前客户的回应”。系统会结合当前品牌、行业、客户类型、目标和选中的异议，生成真实顾虑判断、回应话术与下一步动作。

保存方案后，进入“我的记录”打开该客户，可在“拜访回写”中更新推进状态、下次跟进日期、拜访反馈和异议处理结果。保存后这些信息会留在当前浏览器，记录列表会展示状态和跟进日期，形成“诊断—类型—攻单—异议—复盘”的闭环。

## 6. 跟进提醒、待办与团队迁移

进入“我的记录”后，顶部会显示待办提醒数量、已排期数量以及团队迁移入口。待办提醒包含逾期、今日和未来三天内到期的客户，销售可以直接点击客户进入详情；记录列表同时显示推进状态、跟进状态和下次日期。

在客户详情中填写拜访反馈与异议处理结果并保存后，系统会自动生成“下一次攻单提示”，将客户反馈、未解决异议和下次跟进日期组合成下一次拜访的准备建议。该摘要保存在当前浏览器，刷新页面后仍可复习。

团队协作前可点击“导出”，下载带版本号和导出时间的 JSON 客户记录包；在另一台设备点击“导入”即可选择 JSON 文件，系统会按记录 ID 合并，导入记录优先、未冲突的本机记录保留。导入失败时页面会提示格式问题，不会覆盖原有记录。

## 7. 客户画像与攻单结论

生成结果由四层组成。

第一层是**客户画像**，包括客户所处发展阶段、决策驱动力、市场张力、本次拜访目标、主类型和次类型。画像摘要会把问诊原始信息与 AI 判断连接起来，帮助销售快速复述客户处境。

第二层是**结论**，包括主类型、次类型、判断置信度、识别依据和核心矛盾。主类型用于决定首要切入点，次类型用于提醒销售不要忽略客户的第二诉求。案例匹配由系统按照主类型和次类型自动完成，不需要销售手动挑选。

第三层是**策略与话术**，包括攻单策略、五步法动作、一句话破冰、核心沟通话术和高频异议处理。销售应先验证判断，再使用话术，避免机械照读。

第四层是**行动计划**，包括建议下一步、匹配案例以及会前、会中、会后的推进安排。行动计划应被转化为具体动作，例如确认试点城市、约到老板、准备同类案例或约定下一次复盘时间。

## 8. 七大客户类型速查

“七大类型”页面支持关键词搜索，可按名称、短句、切入点和识别信号检索。每张类型卡包含识别信号、切入点、沟通忌讳、破冰话术、核心沟通话术、策略和对应案例。

| 客户类型 | 典型切入点 | 沟通重点 |
|---|---|---|
| 品牌野心型 | 资产思维 | 把投放从费用翻译为长期品牌资产 |
| 定位卡位型 | 心智货架 | 抢占单一品类或场景的唯一联想 |
| 品类开创者型 | 教育速度 | 先完成品类教育，再争取品类定义权 |
| 竞争突围型 | 饱和攻击 | 集中火力放大差异化，避免战线过长 |
| 资本叙事型 | 估值杠杆 | 连接品牌势能、增长曲线与资本信任 |
| 全国化扩张型 | 认知先行 | 核心城市打样，品牌造势先行、渠道承接 |
| 品牌焕新型 | 重新定位 | 用新主张刷新老品牌的市场认知 |

## 9. AI 攻单助手

进入“攻单助手”后，可以输入完整客户背景，也可以使用页面内的示例提示。AI 会在七大类型知识库和五步法上下文中回答，通常输出类型判断、案例建议、话术和下一步动作。

推荐的输入模板是：

```text
客户行业：
客户规模与区域：
老板原话：
当前竞争状态：
本次拜访目标：
已投放渠道及效果：
决策人和决策流程：
当前最大顾虑：
```

如果客户说“太贵了”，不要只让 AI 生成一句反驳，而应补充客户体量、预算、历史投放效果、目标城市和决策人。信息越接近真实拜访，输出越容易落到可执行动作。

## 10. 异议速查

“异议速查”页面覆盖五类高频场景：太贵了、我们再看看、投过线上效果不好、品牌太小、老板不同意。每个场景都包含表层异议、背后真实顾虑和建议回应。

使用时遵循“先确认顾虑，再给回应，最后定动作”的顺序。不要把价格异议直接当成预算问题；它可能代表客户对效果、决策风险或内部共识缺乏信心。对于“老板不同意”，应先追问老板关注的经营指标与决策链，而不是继续重复媒体卖点。

## 11. 保存、复习与 PDF 报告

生成结论后点击“保存方案”，记录会写入当前浏览器，并出现在“我的记录”。记录标题包括主类型和行业，摘要包含客户画像、攻单结论、判断依据、五步法、话术、案例和下一步计划。点击记录可以展开完整方案。

点击客户画像卡片中的“导出 PDF”，系统会在浏览器端生成报告，不上传到服务器。报告文件名格式为：

```text
攻单报告-{行业}客户画像-{YYYY-MM-DD}.pdf
```

报告包含客户画像、发展阶段、决策驱动力、市场张力、拜访目标、类型判断、判断依据、攻单策略、破冰话术、核心沟通话术、匹配案例和会前/会中/会后计划。若浏览器阻止下载，请检查浏览器下载权限或允许当前网站创建下载。

## 12. 使用边界与排障

AI 只能基于项目内置知识库和销售输入工作。案例名称由类型匹配函数自动关联，不能把未收录的客户案例当成系统事实。知识库案例中的数字属于文档案例数据，不应直接承诺为客户结果。

如果页面加载后记录为空，先确认是否更换了浏览器、设备或无痕窗口。如果 AI 输出格式异常，可以检查关键输入是否包含特殊字符并重试。如果 PDF 生成失败，先刷新页面后再次导出，并检查浏览器下载权限。若本地记录仍无法恢复，可将已保存方案复制到团队 CRM 或文档系统中。

### 拜访复盘与下一次攻单

打开“我的记录”后，选择本次结果，填写新增客户信号、拜访反馈、异议处理结果和下一次推进目标，再点击“保存复盘信息”。点击“生成下一次攻单”后，系统会给出事实摘要、当前阻力、下一次问题、建议动作、准备材料和三种跟进消息。

三种消息分别适用于关系维护、专业推进和决策确认。每条消息都可以单独复制、回写采用；点击“重新生成”会基于当前复盘重新生成三种消息。发送前应核对品牌名称、事实和时间，不应将“待确认”内容当作客户事实。

### 记录迁移与日历

点击“导入”后，系统先展示新增、冲突、重复和无效数量，不会立即覆盖本机数据。确认时可选择导入文件优先或保留本机优先；完成后可撤销最近一次导入。点击“导出”生成版本 2 JSON，版本 1 文件仍可导入。

“ICS”按钮会将已经设置下次跟进日期的记录导出为日历文件，可导入常见日历应用；没有跟进日期的记录不会生成日历事件。

## 13. 版本说明

当前版本的主流程是免登录使用与浏览器本地保存。服务端仍保留基于 OAuth 和数据库的受保护记录接口，主要面向后续团队协作或云端同步扩展；当前前端工作台默认使用本地记录，不要求账户登录。
