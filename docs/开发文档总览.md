## 4. 核心功能模块
- **Auth**：JWT 登录，admin/user 角色
- **Customers**：客户 CRUD、类型标注、owner 隔离
- **Briefing**：会前简报生成（规则 + 历史记录）
- **Assist**：会中辅助（实时检索 + 话术建议）
- **Followup**：会后跟进包生成
- **Chat**：多会话聊天（支持绑定客户）
- **Knowledge**：知识库管理（类型、案例、话术、证言）
- **Research**：外部数据层（文档导入、页面抓取、联网背调、FTS5 检索）
- **Analyze**：客户快速分析
- **Dashboard**：数据看板

## 5. 开发原则
- 先跑通最小闭环：录入客户 -> 类型判断 -> 会前简报
- 先规则/检索，后生成：避免一开始就过度依赖 LLM
- 知识可追溯：建议必须能关联到知识库来源
- 数据隔离：客户数据按 owner 隔离，知识库按角色控制
- 现场可用优先：会前/会中场景优先于后台大报表

## 7. 当前阶段
- 阶段：v0.9.0 — 现场可用已完成（会中实时辅助、PWA、移动端适配、离线兜底）

## 8. 测试与运行保障
- 固定重启脚本：`scripts/run_tests_with_restart.sh`，每次测试前会终止旧进程、初始化 SQLite、重启 backend/frontend、校验登录后跑 pytest
- 前端冒烟脚本：`scripts/frontend_smoke_test.py`，覆盖登录、会话、会前/会中/会后、来源卡、权限等关键路径
- 调试日志：backend 看 `/tmp/sales-backend.log`，frontend 看 `/tmp/sales-frontend.log`
