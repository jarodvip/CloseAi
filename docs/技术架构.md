# 技术架构

## 1. 总体架构
- 前端：静态 Web 单页应用，直接调用后端 API
- 后端：FastAPI + SQLAlchemy + SQLite + FTS5
- 数据层：关系型模型 + 知识库基础表 + ResearchChunk 外部数据层
- AI 层：规则生成 + 知识库检索 + LLM 增强（已预留接口）

## 2. 后端模块

### 2.1 入口与配置
- `app/main.py`：应用入口、路由注册、中间件（CORS、请求大小限制）、全局异常处理
- `app/core/config.py`：环境变量（LLM、JWT、数据库）
- `app/core/security.py`：JWT 创建/解析、密码哈希
- `app/core/deps.py`：登录态依赖、权限校验（admin/user）、owner 隔离

### 2.2 路由层 (`app/api/v1/routes/`)
- `auth.py`：登录、当前用户
- `customers.py`：客户 CRUD、类型更新、owner 隔离
- `briefing.py`：会前简报生成、简报历史
- `interactions.py`：跟进记录、会中辅助、会后跟进
- `knowledge.py`：知识库查询与管理（管理员可写）
- `chat.py`：会话/消息 CRUD、AI 回复
- `analyze.py`：客户快速分析并创建
- `dashboard.py`：数据看板统计
- `research.py`：外部数据检索、URL 导入、客户背调

### 2.3 服务层 (`app/core/domain/services/`)
- `auth_service.py`：用户认证、JWT 构建
- `customer_service.py`：客户 CRUD、列表过滤
- `briefing_service.py`：会前简报构建（知识库检索 + 规则生成）
- `briefing.py`：简报 Agent（LLM 增强）
- `interaction_service.py`：跟进记录 CRUD
- `assist_service.py`：会中辅助（检索 + 话术生成）
- `followup_service.py`：会后跟进包生成
- `chat_service.py`：会话/消息管理 + AI 回复
- `knowledge_service.py`：知识库查询 + FTS5 检索
- `research_service.py`：ResearchChunk 摄取、FTS5 全文检索、背调执行
- `llm_service.py`：LLM 调用适配层（普通生成 / 联网搜索）
- `analysis_service.py`：客户类型推断

### 2.4 数据模型 (`app/models/`)
- `user.py`：用户表（username, hashed_password, role）
- `customer.py`：客户表（7 类客户类型、owner 关联）
- `interaction.py`：跟进记录表
- `briefing.py`：简报历史表
- `chat.py`：会话表 + 消息表
- `knowledge.py`：客户类型知识、案例、话术、证据
- `research.py`：外部数据文本块（支持 doc/web/research 三种来源）

### 2.5 外部数据层
- `app/agent/briefing.py`：简报生成 Agent
- `backend/scripts/import_docs.py`：PDF/Word 批量导入脚本

## 3. 权限与安全
- 使用 JWT Bearer 鉴权
- 登录后可访问客户与会话能力
- 知识库写入接口仅允许 `admin` 角色
- Research 检索与删除仅 `admin`；URL 导入仅 `admin`；客户背调 owner 可见
- 演示环境提供默认账号：`admin/admin123`（管理员）、`sales/sales123`（普通销售）

## 4. 前端模块
- `frontend/src/index.html`：登录页、销售工作台、各功能页面、弹窗
- `frontend/src/app.js`：API 调用、状态管理、页面切换逻辑
- `frontend/prototype.html`：原型页面

## 5. 部署建议
- 后端运行：`cd backend && source .venv/bin/activate && uvicorn app.main:app --reload --port 8002`
- 前端运行：`cd frontend && python3 -m http.server 8080`
- 数据文件：`backend/sales_agent.db`
- API 文档：`http://localhost:8002/docs`

## 6. 外部数据层技术要点
- SQLite FTS5 虚表 `research_chunks_fts`，jieba 预分词
- 三个摄取入口统一走 `ingest_text()` 分块入库
- `embedding` 列已预留（LargeBinary），二期可平滑升级向量检索
