# 数据模型设计

## 1. 客户表 customers
- id：主键
- name：客户名称
- industry：行业
- revenue_range：营收区间
- stage：发展阶段
- region：区域
- primary_type：主类型
- secondary_type：次类型
- type_confidence：类型置信度
- type_evidence：类型判断依据
- created_at / updated_at

## 2. 跟进记录表 interactions
- id：主键
- customer_id：客户ID
- stage：会前/会中/会后
- summary：会话摘要
- decisions：决策结果
- pending_actions：待办动作
- created_at

## 3. 任务表 tasks
- id：主键
- customer_id：客户ID
- title：任务标题
- due_at：截止时间
- status：待办/已完成
- owner：负责人

## 4. 知识库基础表
- customer_type_knowledge：客户类型结构化知识
- cases：案例库
- scripts：话术库
- evidence：数据证言库

## 5. 索引建议
- customers：name、primary_type、industry
- interactions：customer_id、created_at
- tasks：customer_id、status、due_at
